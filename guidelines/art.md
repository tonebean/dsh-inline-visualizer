# art.md — 插画 / 示意艺术模块

> 适用：用于**建立直觉**的插画、剖面图、抽象空间隐喻、装饰性图形。**须与 `_core.md` 同时加载。**

---

## 1. 目标

让抽象概念**可感**。不追求写实，追求「一眼看懂结构或关系」。

## 2. 两类主体

| 类型 | 处理方式 |
|---|---|
| **实物主体** | 画简化版：剖面、切面。例：热水器 = 罐体 + 底部火源 |
| **抽象主体** | 发明空间隐喻。例：Transformer = 一叠水平层板；哈希函数 = 漏斗撒入多个桶 |

## 3. 用色

- **颜色编码强度，而非类别**。暖色系 = 热 / 能量 / 活跃；冷色系 = 冷 / 静 / 休眠。
  - 冷端：`var(--viz-blue-100)` → `var(--viz-blue-500)`；暖端：`var(--viz-amber-100)` → `var(--viz-red-500)`。
- 单图**最多一个** `<linearGradient>`，且仅用于表达连续物理属性（如温度梯度）。其余一律纯色。
  - `<stop>` 的 `stop-color` 走 `style`：`<stop offset="0" style="stop-color: var(--viz-blue-300)"/>`（`stop-color="var(--x)"` 无效）。
- 允许 `@keyframes` 动画（仅 `transform` / `opacity`，周期 < 2s），且包在 `@media (prefers-reduced-motion: no-preference)`。

## 4. 标注

- 标签放在**被画物体之外**，用细引线（0.5px、虚线）连接。
- 标签文字走 `_core.md` 的字号与字重规范。
- 不要在图内写长句解释——解释放正文。

## 5. 优先交互

- 若真实系统有可操作的控件（滑块、开关、旋钮），**优先把它画成可交互的**，而不是静态图。
- 交互组件的约束见 `interactive.md`。

## 6. 禁止

- 禁止写实照片质感、禁止纹理噪声、禁止投影浮雕。
- 禁止为「好看」而加装饰元素——每个元素都应承载信息。
