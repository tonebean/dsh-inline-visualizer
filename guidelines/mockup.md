# mockup.md — UI 原型模块

> 适用：界面稿、组件原型、表单、列表、卡片布局。**须与 `_core.md` 同时加载。**

---

## 1. 基本约定

- 用 HTML + CSS 片段（非 SVG），以便复用真实布局能力。
- 外层容器**透明背景**，由宿主提供页面底色。
- 宽度自适应，不写死 px 宽度（除非模拟固定尺寸设备）。

## 2. 组件规格

| 组件 | 高度 | 圆角 | 说明 |
|---|---|---|---|
| 输入框 | 36px | `var(--viz-radius-sm)` | 内边距 10px 12px |
| 按钮 | 36px | `var(--viz-radius-sm)` | 主按钮填充 500，次按钮描边 |
| 卡片 | 自适应 | `var(--viz-radius-md)` | 内边距 16，边框 0.5px |
| 标签/徽章 | 22px | 999px | 字号 12，内边距 4px 8px |

- 组件间距用 4 的倍数。
- 表单字段**纵向排列**，字段间距 16。

## 3. 状态

- 需体现的典型状态：默认 / 悬停 / 聚焦 / 禁用 / 错误。
- 聚焦态：边框用 `var(--viz-info)`，2px 或加 3px 柔和外环（`box-shadow: 0 0 0 3px color-mix(...)` 不可用时改用降低透明度的边框色）。
- 错误态：边框与提示文字用 `var(--viz-danger)`。
- 禁用态：整体降透明度至 0.5，不改变色相。

## 4. 用色

- 主操作 = 蓝（`var(--viz-blue-500)`）。危险操作 = 红（`var(--viz-danger)`）。
- 背景层级：页面 `var(--viz-bg-tertiary)`，卡片 `var(--viz-bg-primary)`，次级区域 `var(--viz-bg-secondary)`。
- 文字层级：正文 `var(--viz-text-primary)`，说明 `var(--viz-text-secondary)`，占位符 `var(--viz-text-tertiary)`。

## 5. 禁止

- 禁止使用外部图标字体；图标用内联 SVG 或几何形状。
- 禁止 `position: fixed`；模拟吸顶用容器内 sticky 或直接平铺。
- 禁止写死深色背景以「看起来高级」——必须随主题（优先用上面这些随主题自动变化的令牌）。
